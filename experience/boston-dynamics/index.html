01 / Adjustable test hardware

Dual-axis gripper test mount

I designed a custom benchtop mount for evaluating competitor grippers, with two Hirth joints to adjust pitch and yaw. The design requirement was a load exceeding 30 kg at a 400 mm lever arm.

Dual supportA two-sided structure carries the cantilevered gripper load.

Constrained assemblyPin-and-slot features locate the custom CNC-machined metal parts.

Indexed adjustmentHirth interfaces set the test orientation before loading.

02 / Atlas leg stiffness testing

100 kg test-mass winch

I developed a ratcheting winch fixture to raise a 100 kg test mass for Atlas leg stiffness testing. The assembly integrates the winch, cable routing, and custom mounting structure into the test setup.

03 / Human-to-robot interface

IMU glove and gripper interface

I built the wearable adaptation for competitor grippers and helped integrate an IMU-equipped glove that maps human hand motion into robot grasping. The demo shows the interface picking up a small object.

04 / Gripper evaluation

Gauntlet test stand

A modular, 3D-printed test stand for evaluating competitor grippers across a range of object sizes and manipulation tasks.

3D-printed test fixtures

Modular dexterity tasks

The panels provide repeatable tasks for testing grasping and dexterity. Size labels and interlocking pieces allow the setup to be reconfigured.
